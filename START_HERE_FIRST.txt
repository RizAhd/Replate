🛠️ TROUBLESHOOTING:
══════════════════

BUILD FAILS?
→ Check gradle.properties exists
→ Verify internet (dependencies download)
→ Check Android SDK path in local.properties
→ Try: File → Invalidate Caches → Restart

APP CRASHES?
→ Check google-services.json is in app folder
→ Verify Firebase project is active
→ Check all activities in AndroidManifest.xml
→ Try: Build → Clean, then rebuild

PAYHERE NOT OPENING?
→ Check internet connection
→ Verify PayHere SDK in build.gradle
→ Check Merchant ID in code
→ Try: Close and reopen checkout

FIREBASE NOT SYNCING?
→ Check Firebase Console → Authentication (user exists?)
→ Verify internet connection
→ Check Firebase rules allow write
→ Try: Force-restart app
